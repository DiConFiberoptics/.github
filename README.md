# DiCon Fiberoptics organization profile

The public organization introduction is maintained in [profile/README.md](profile/README.md).

- Use pull requests for updates to the public profile.
- Base company and product statements on the [official website](https://www.diconfiberoptics.com/), [company overview](https://www.diconfiberoptics.com/about/company.php) and [contact page](https://www.diconfiberoptics.com/contact.php).
- Keep confidential project information and credentials out of this public repository.
- The profile uses the organization's company avatar. A copy of the supplied logo artwork is retained in [profile/assets/dicon-logo.png](profile/assets/dicon-logo.png); preserve the artwork when changing presentation.

## Brand animation

[profile/assets/dicon-gfi-brand.gif](profile/assets/dicon-gfi-brand.gif) is a silent, looping excerpt of the existing [GFI / DiCon corporate profile](https://gfi-apps.diconcloud.com/gfi-corporate-profile/), version 1.4.0. It retains the original animation and logo artwork; no AI redraw was used.

- Source scenes: opening 00:02–00:07.8, followed by closing 01:58.4–02:04.
- Output: 11.4 seconds, 800 × 450 pixels, 10 fps, 96-color GIF, approximately 3.6 MiB.
- Exported with the source project's film renderer, then trimmed, concatenated and palette-encoded using FFmpeg.
- Keep the image and its caption linked to the full corporate profile. Do not embed scripts or the full player in the organization README.
